# TripStack

TripStack is a React Native travel-planning app that organizes flights, stays, activities, and budgets into one shareable itinerary.

## Overview
Users can paste booking confirmations or describe a trip, and the app builds a structured day-by-day plan with maps, costs, and reminders.

## Problem
Trip details are usually scattered across email, screenshots, maps, and group chats.

## Solution
TripStack creates one organized itinerary that travelers can edit, share, and use offline.

## Features
- AI itinerary generation
- Day-by-day schedule
- Map views
- Budget tracking
- Document and booking storage
- Offline access

## Tech Stack
- React Native + Expo
- TypeScript
- Expo Maps / MapView
- OpenAI API
- SQLite
- Supabase
